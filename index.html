Tester Notes / Known Bugs

This is a private test build. Some areas are unfinished, and progress wording is intentionally cautious.

  • Some question banks are still small, so items may repeat.
  • Production cards are self-marked practice only; Ozmosis does not auto-grade them.
  • The Learning Map shows evidence, not mastery.
  • Delayed review is not active yet.
  • Review practice is optional and appears only when older auto-graded items are available; it is not a mastery or durability label.
  • Suggestions are early and rules-based.

Please report screens you cannot leave, hidden buttons, blocked footers, confusing feedback, repeated or unfair questions, misleading progress labels, and keyboard or scroll problems.

Dev Tools

Temporäre Prototypen, bevor sie in den normalen Lernfluss eingebaut werden.

Debug snapshot

Copy current route, item, viewport, storage, evidence, and layout warning data for troubleshooting.

Review readiness snapshot

QA-only readiness snapshot. No review schedule is active. No learner-facing durability states are active. No mastery or B1-readiness claim is made.

Durability QA audit

Internal audit of delayed-attempt and review evidence. It does not activate durable, due, overdue, or scheduler states.

Review eligibility rules

Internal eligibility summary only. It does not create a learner-facing review route, schedule, or durability label.

Review system stability

Internal audit of optional Review Practice visibility, empty state, evidence context, confidence, and export/import policy.

Review candidate preview

No-save preview of future review candidates and exclusion reasons. This is not a learner-facing review route.

Metadata review coverage

Read-time metadata audit for review coverage. No content, evidence, score, or storage data is changed.

B1 coverage audit

Item-count coverage audit for the planned B1 spine. This is not a learner progress, mastery, or readiness claim.

Manual item preview

Find a B1 item by ID or text and inspect it in DEV PREVIEW mode. No progress or evidence is saved.

Repair queue preview

Inspect computed repair queues from current evidence. Preview only; no progress or evidence is saved.
