## v0.80.14.8 - Restore Medal Star Visual System

- Restored the B1 Progress Path and task-screen star visual language to a medal/rank hierarchy instead of green success-style stars.
- Added explicit star colour tokens for empty, bronze, brass, silver, electrum, gold, and matching glow states.
- Reused and extended the existing `.b1Stars` / `.b1Star` component classes for B1 Path task strips, post-answer star updates, and compact star glyphs.
- Replaced green B1 Path stacked star bars with metal-tier threshold bars: 1 star bronze, 2 stars brass, 3 stars silver, 4 stars electrum, and 5 stars gold.
- Simplified task-screen star copy so normal B1 tasks show a compact medal strip and short label such as `Got right twice`, without large `Practice progress` banners or internal category/task labels.
- Simplified post-answer star copy:
  - correct answers show medal stars plus concise copy such as `Now got right 3 times.`;
  - wrong answers show `No new star. This will return for practice.`;

  - production practice shows `Production practised.` and `Not star-rated.`.
- Kept correctness feedback green/red where appropriate, while separating that meaning from B1 progress stars.
- Preserved the existing star logic: stars still come only from unassisted correct auto-graded repetitions for the same practice target.
- Preserved production as self-marked/practised-only and Diagnostic Sprint as snapshot-only.
- Preserved Home compact progress cards, Learning Map B1 Path details, scoring, correctness rules, protected storage keys, additive path unlock overrides, export/import compatibility, content banks, route composition, Today B1 Sprint composition, Diagnostic Sprint composition, B1-only active scope, and German LTR behaviour under Arabic UI.
