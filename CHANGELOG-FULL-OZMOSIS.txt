# Ozmosis Master Changelog

## Purpose

This is the canonical cumulative changelist for Ozmosis.

Git is the saved history of changes. Commit messages are useful, but they are not enough by themselves. Versioned changelogs, README files, source briefs, roadmaps, QA reports, and committed logs can contain extra detail. This file collects those sources in one place so future work has one master changelist to check.

Future runs must add to this file, not replace it.

This is the only changelog moving forward. Do not create standalone `CHANGELOG-v*.txt` files unless the user explicitly asks for a historical export.

## Append / Update Policy

- Preserve existing content.
- Append missing or new information.
- Add correction notes instead of silently changing historical entries.
- Keep original source wording where practical.
- Keep the source ledger at the bottom of this file.
- Do not turn planned work into completed work.
- Do not claim tests passed unless a source says they were run.
