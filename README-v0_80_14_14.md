# Ozmosis v0.80.14.14

## Progress Summary Cache / Interaction Latency Hotfix

Ozmosis v0.80.14.14 is a narrow performance and progress-state patch after v0.80.14.13. It adds an additive B1 progress summary cache so ordinary Home, route, and progress rendering can read compact state instead of repeatedly scanning all raw evidence and content.

Raw evidence remains the audit trail. The new summary is a rebuildable cache.

## What Changed

- Added `ozmosis_b1_progress_summary_v1` as a derived localStorage cache.
- Added summary rebuild from existing B1 evidence.
- Added incremental summary updates when B1 evidence is written.
- Deferred the heavier path aggregate refresh out of the immediate answer-submit path.
- Added a static in-memory B1 content index for route/content lookup.
- Updated Home rendering to use compact summary/path data instead of building Learning Map, Skill Matrix, evidence summary, and recommendation data on every render.
- Deferred Review practice preview work until after Home renders or until Review practice is opened.
- Added additive export metadata for the progress summary.
- Rebuilt the summary from raw evidence after import, including older exports without a summary cache.
- Added dev-only performance timings for summary rebuild, incremental update, Home render, route start, Review practice, Learning Map, Settings, export, and import paths.
- Added a local QA gate at `_development-files/v0801414_progress_summary_cache_gate.cjs`.

## Preserved

- Main deployed file: `index.html`.
- Static browser app architecture.

- German learning content remains LTR under Arabic support language.
