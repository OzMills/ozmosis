## Patch Summary

v0.80.14.18.1 is a narrow acceptance hotfix for route isolation.

v0.80.14.18 claimed that Learning Map and Settings no longer appeared below Home, but manual testing showed that claim was not yet true. This patch fixes the root cause.

It:

- restores one clear active screen at a time;
- prevents hidden Home from being forced visible by late landing CSS;
- routes Home, Learning Map, Settings, hubs, setup, and practice starts through a shared active-screen helper;
- keeps Dev Tools as an overlay while hiding persistent route screens behind it;
- preserves Export Save and Import Save in Settings / Data.

## Preserved Behaviour

- German-learning content unchanged.
- Task answers unchanged.
- Scoring semantics unchanged.
- Star-earning semantics unchanged.
- Star Threshold Overlay calculation unchanged.
- localStorage key names unchanged.
- Export Save / Import Save workflow preserved.
- No backend, framework, build step, package manager, dependency, account, analytics, API call, runtime AI, or runtime German generation added.
