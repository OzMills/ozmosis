# Ozmosis B1-01 Vocabulary / Activity Coverage Audit

Status: Audit snapshot after original Phase 3A and top-up Phase 3A QA.
Module: B1-01 — Getting started at work/course.
Scope: vocabulary, activity coverage, evidence quality, mobile fit, and next-content decision.

## Executive verdict

HEALTHY_BUT_NEEDS_LESSON_LAYER

B1-01 has enough practice coverage to function as an entry module. It should not be expanded to 100 normal practice exercises. The current practice set already over-emphasises simple survival language and early sentence patterns enough that adding many more normal exercises would produce repetition or false B1 depth.

The useful next expansion is a separate lesson/reminder layer and later review/checkpoint logic, not another large exercise batch.

## Main findings

### What is well tested

| Area | Evidence | Strongest item types | Caveat |
|---|---|---|---|
| V2 after fronted time/place phrase | Many cloze, Satzbau, repair, recognition items | Satzbau, Reparatur, Umformen | Do not add many more identical Heute/Im Kurs forms. |
| Basic W-question word order | `Wo ist...?`, `Wo finde...?` | Satzbau, repair, cloze | Good enough for B1-01. |
| Yes/no question order | `Brauche ich...?`, `Ist...?`, `Haben Sie...?` | Satzbau, recognition, cloze | Some statement/question contrast risk remains. |
| `mein/meine` with familiar nouns | Kurs, Arbeit, App, Heft, Unterlagen | Cloze, repair, Satzbau, contrast | Keep as awareness, not full article/case control. |
| Noun capitalisation | Kurs, Hilfe, App, Heft, Unterlagen | Repair and cloze | Evidence should be weak/supportive where spelling is the only target. |

### What is not well tested

| Area | Current evidence | Problem | Recommendation |
|---|---|---|---|
| Discourse function of introduction | Mostly sentence-level | Not enough sequencing of 2–3 sentences | Add lesson/reminder cards and controlled production prompts later. |
| Vocabulary in realistic course routines | Thin | `Kurs/App/Heft/Unterlagen` dominate | Add later only through scenarios, not flashcards. |
| Contrastive diagnosis | Only 3 contrast items | Learner may not know why a distractor is wrong | Add “why wrong?” / minimal-pair cards later. |
| Delayed review/checkpoint | Not active here | Same-day correctness is not retention | Add review/checkpoint route later, not as more B1-01 content now. |
| Support fading | Present in metadata, not a content layer | Learners need reminders before supported removal | Add micro-reminder layer. |

### Over-tested / inflated areas

| Area | Evidence | Problem | Action |
|---|---|---|---|
| `Ich brauche...` | appears in roughly 18/67 practice items when `Brauche` questions are included | The phrase is A1/A2 by itself and risks becoming fake B1 evidence | Keep as survival/scaffold; cap future normal practice additions at 0–2. |
| V2 with `Heute/Im Kurs/Am Montag` | heavily represented across cloze/Satzbau/repair | Good target, but close to saturation | Stop adding ordinary V2 items; use review/transfer later. |
| Course nouns as spelling targets | Kurs/App/Heft/Unterlagen recur | Can become capitalisation drill rather than communication | Keep only in context; no isolated spelling expansion. |

## Recommended structure

Do not aim for 100 ordinary B1-01 practice items. A defensible target is:

| Layer | Current count | Recommended final count | Action |
|---|---:|---:|---|
| Core auto-graded practice | about 55–60 | 60–65 | Stop or add only targeted repairs later. |
| Auto-supported mechanics/vocab | about 7–10 | 8–10 | Keep weak; do not inflate. |
| Controlled production | 6 | 8–10 | Optional small top-up later. |
| Lesson/notice/reminder cards | 3 | 15–20 | Build separately; do not count as evidence. |
| Checkpoint/review cards | 0 | 8–12 | Later, once review infrastructure is ready. |

If “100” excludes notice/concept cards, then 100 is not the right target for B1-01 initial content. It would require too much repetition. If “100” includes later review/checkpoint cards, it can be structurally valid, but those should not be authored as ordinary new exercises now.

## Content generation decision

B. Yes, but only lesson/reminder cards.

Do not generate more normal B1-01 practice yet. Create a lesson/reminder-card layer for the current practice set, then move to B1-02. If exact 100 remains desirable, fill the remaining count later with delayed-review/checkpoint cards after schema/import work, not with more `Ich brauche...` variants.
