## 6. Repair-Edit Prefill Implementation

- Edit-prefill is field-driven by `answerMode:"edit_text"` and/or `prefillRepairText:true`.
- Prefill uses an authored flawed source sentence, not generated German.
- Non-repair task types do not receive repair-edit prefill.
- The input remains LTR.
- The checking path still compares the learner edit with the authored correct sentence.

## 7. Variable-Error Repair Pilot

- Variable-error repair is limited to Cases & Articles.
- Each pilot item has an authored correct sentence and authored error slots.
- Runtime selection is deterministic from the available authored slots.
- A variable item can show one or two authored errors depending on the seed.
- No morphology generator, runtime German generator, dynamic import, backend, dependency, or API call was added.
- Variable-error repair stays under repair task depth and uses edit-text answer mode.
