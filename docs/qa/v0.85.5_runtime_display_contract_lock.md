## 20. Known Risks

The v0.85.5 lock is a runtime safety layer, not source cleanup. Some source rows can still contain internal labels or weak cues and must be handled in v0.85.6+ without changing answer keys or scoring semantics.

The source-cleanup CSV records non-blocking rows because the active runtime contract prevents learner-facing leakage. v0.85.6 should use the v0.85.4 CSVs, the v0.85.5 remaining cleanup CSV, and the current runtime audit as cleanup inputs.
