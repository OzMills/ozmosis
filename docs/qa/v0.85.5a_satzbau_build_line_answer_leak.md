## 4. User-Reported Satzbau Issues

Manual review reported that tapped Satzbau chunks built text inside a text-entry field and that the correct answer order was visible underneath the chunks before answer.

## 5. v0.85.5 Baseline Used

v0.85.5 was used as the accepted runtime display contract baseline. The v0.85.4a Satzbau tap/randomisation and iOS-safe input-size gate was used as the non-regression baseline.

## 6. Satzbau Build-Line Design

Pre-answer Satzbau now renders a visible `Your sentence:` build line. It is a non-input display rail, not an `input` or `textarea`.

## 7. Manual Typing Fallback Decision

Manual typing remains available behind a `Type manually` disclosure. It is secondary and not the primary visible build surface.

## 8. Answer-Leak Root Cause

Satzbau used the normal display cue/support path. For the representative word-order item, that path exposed the correct sentence order as pre-answer gloss text.

## 9. Answer-Leak Fix

Satzbau display model now suppresses pre-answer cue/support rendering that would reveal the correct order. The runtime display contract also excludes Satzbau from the under-contextualised cloze cue requirement.

## 10. Pre-Answer Satzbau Results

Accepted. The gate verified `preAnswerGlossHiddenOrSafe`, `preAnswerCorrectAnswerNotVisible`, and `preAnswerLearnerCueOrderNotVisible`.

## 11. Tap-to-Build Results

Accepted. The gate verified that chunks are focusable/tappable, tapping builds the visible build line, selected state remains visible, and the build line is not an input.

## 12. Clear/Reset Results

Accepted. Clear/reset empties selected chunks and the visible build line.

## 13. Manual Typing Fallback Results

Accepted. The fallback exists, is closed by default, opens when requested, and preserves manual input.

## 14. Post-Answer Feedback Results

Accepted. The correct sentence is visible after answer, and existing answer checking remains preserved.

## 15. Runtime Display Contract Non-Regression

## 16. Satzbau Randomisation Non-Regression

## 17. iOS Input Zoom Repair Non-Regression
