## 4. Current Skill Matrix Logic Before Patch

The v0.57 Skill Matrix already separated rows by Learning Map skill node and columns by task depth. It already showed conservative states and limitation copy for production, diagnostic, derived metadata, and delayed review. The risk was that cells with several correct-but-scaffolded, diagnostic-only, production-only, or unknown-depth records could still appear stronger than warranted.

## 5. Evidence Inflation Risks Found

- One or two records needed explicit thin-sample metadata.
- Scaffolded-majority cells could otherwise look like ordinary unassisted evidence.
- Diagnostic-only cells needed a hard cap below stronger states.
- Self-marked production-only cells needed a hard cap below stronger states.
- Unknown or legacy task-depth cells needed explicit QA visibility.

## 6. Sample Size Handling

Added `sampleSizeLabel` and `thin_sample` QA flags. Learner-facing matrix cells may now show a compact `Thin sample` badge. Empty cells remain neutral and display `Not tested`.

## 7. Task-Depth Separation

Existing task-depth separation is preserved. Repair and contrast synthetic records still populate repair and contrast cells separately. Recognition limitations are tracked as QA metadata so recognition evidence does not imply repair or production control.

## 8. Support-Level Handling

Added Skill Matrix support mix QA metadata. Cells with scaffolded-majority support are flagged with `scaffolded_majority`, capped below stronger states, and may show a compact `Scaffolded` badge.

## 9. Production Evidence Handling

Production-only cells are flagged with `production_self_marked_only`, capped below stronger states, and continue to show `Self-marked practice`. Production remains practice evidence only and is not auto-graded correctness.

## 10. Diagnostic Evidence Handling

Diagnostic-only cells are flagged with `diagnostic_only`, capped below stronger states, and continue to show diagnostic snapshot copy.

## 11. Derived Metadata Handling

Derived metadata remains visible as a limitation and `Derived metadata` badge. Mostly-derived cells are also counted in debug summaries.

## 12. Empty Cell Handling

Empty cells remain `Not tested`; they are not styled or labelled as failure. Existing limitation copy still says empty cells are not failure.

## 13. Unknown / Legacy Task Depth Handling

Unknown task-depth evidence is flagged with `unknown_legacy_task_depth`, counted in debug summaries, and shown only when evidence exists.

## 14. Learner-Facing Copy Audit

Active learner-facing states remain limited to:

- Not tested
- Not enough evidence
- Introduced
- Emerging
- Developing

No active mastery, durability, readiness, pass/fail, misconception, slipping, over-practised, overdue-review, rank, or broad-completion percentage claims were added.
