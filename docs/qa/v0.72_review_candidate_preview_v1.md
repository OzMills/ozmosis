## 4. Candidate Preview Scope

v0.72 adds a Dev Tools-only review candidate preview. It is no-save and does not create a learner-facing review route, Home review recommendation, review scheduler, due/overdue copy, durability label, storage mutation, or evidence record.

## 5. Candidate Preview Implementation

Added `buildB1ReviewCandidatePreview(records, eligibility)`, using v0.71 eligibility rules to produce preview rows with:

- `itemId`
- safe display label
- skill tags
- task type and task depths
- last auto-graded age
- attempt counts
- candidate quality
- candidate/exclusion reason
- route-fit check
- current content availability

## 6. Quality Levels

Implemented preview quality labels:

- `preview_ready`
- `missing_timestamp`
- `missing_item`
- `diagnostic_only`
- `self_marked_only`
- `too_recent`
- `too_little_evidence`
- `unsupported_task_type`

## 7. Dev Tools Impact

Added a Dev Tools-only `Review candidate preview` section. It renders candidate rows and limitations without saving progress/evidence.

## 8. Debug / Tester Report Impact

Candidate preview metadata is exposed through:

- `buildDebugSnapshot().reviewCandidatePreview`
- `testerReportSummary().reviewCandidatePreview`
- `window.ozmosisB1Debug().reviewCandidatePreview`
