## Implementation Result

- Confidence guidance is now a separate `b1ConfidenceGuidance` paragraph.
- `Weiter` is hidden while required answer confidence is pending.
- Confidence selection advances normal auto-graded `choice` and `typed` B1 evidence.
- `mark_practised` production evidence is excluded from confidence auto-advance.
- Typed cloze `Teach me` and `Prüfen` use the same `rightAction` grid slot.
- Translation/support copy now uses `Show translation`, `Hide translation`, `Translation`, and `Meaning / translation`.
- Bare `Corrected.` fallback was removed.
- Learner-facing `<summary>Explain</summary>` labels were replaced.
- Redundant `Selected answer:` feedback was removed.
- `Welche Form ist höflicher?` fallback was replaced with `Welche Form passt in dieser Situation am besten?`.
