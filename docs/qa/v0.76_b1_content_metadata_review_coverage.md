## 4. Metadata Audit Method

v0.76 adds read-time metadata coverage helpers. They inspect current registry items and compute derived metadata only for QA/review coverage reporting. They do not rewrite content-bank files, mutate evidence, change scoring, or store metadata in localStorage.

## 6. Metadata Repairs Applied

Repairs are computed at read time only:

- Derived review groups from bank, task depth, and item family/focus.
- Derived target IDs from bank, task depth, focus, and target/answer/family.
- Derived variant-family fallback when explicit metadata is missing.
- Derived contrast and repair groups from existing contrast targets/rules.
- Derived support policy from support visibility fields, support text, or production-card status.
- Added provenance flags for explicit, derived, or missing metadata.
