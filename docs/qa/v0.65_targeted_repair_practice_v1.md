## 4. Targeted Repair Practice Implementation

Added `targeted_repair` practice mode that starts only from a high-quality computed repair queue and runs through the existing B1 practice shell.

## 5. Queue Quality Gate

No queue or low-quality queue means no targeted start. Valid queues require routeable candidates and at least four matching existing items.

## 6. Existing Item Use

Targeted repair practice uses existing registry items only. No generated questions or content-bank mutations were added.

## 7. Learning Map Entry Point

Learning Map shows `Start repair practice` only where a routeable candidate has a valid queue.

## 8. Suggested Next Practice Entry Point

Suggested Next Practice can route to targeted repair only when a high-quality queue exists. Otherwise it falls back to existing conservative routes.

## 9. Practice Session Flow

Targeted repair uses the existing answer, feedback, confidence, continue, and completion flow.

## 10. Completion Flow

Completion copy says the practice is complete, shows attempted items, and returns to Learning Map without claiming mastery or that the issue is fixed.

## 11. Evidence Metadata Impact

Each answered item records normal B1 evidence plus additive `targetedRepair`, `repairQueueId`, and `sourceCandidateId` metadata.

## 12. Scoring Impact

Scoring semantics were not changed globally. Targeted repair uses normal item evidence and existing correctness checks.

## 13. localStorage Impact

No storage keys were added or renamed. Queue metadata is additive on evidence records only when the learner answers a targeted repair item.

## 14. Export/Import Impact

Export/import shape is backward-compatible. The gate covered current import, older import, and malformed import handling.

## 15. Content Bank Impact

No content-bank source files, item IDs, answers, or statuses were changed.
