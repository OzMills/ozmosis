## 4. Current Confidence Flow Before Patch

Verified before editing:

- `appendB1EvidenceRecord(...)` created a single evidence record with `confidence:null`.
- `checkB1Answer(...)` appended evidence once and stored `b1Runtime.currentEvidenceRecordId`.
- `markB1ProductionPractised(...)` appended one conservative production evidence record and stored `b1Runtime.currentEvidenceRecordId`.
- `renderB1ConfidenceControls(selected)` displayed the confidence row only when a current evidence record existed.
- `updateLatestB1EvidenceConfidence(value)` accepted only `sure`, `unsure`, or `guessed`.
- The pre-patch confidence click handler only called `updateLatestB1EvidenceConfidence(...)` and did not advance.

## 5. Confidence-as-Next Implementation

Added small helper functions:

- `b1CurrentEvidenceRecord()`
- `b1ConfidenceLabelsForRecord(record)`
- `b1ConfidenceAutoAdvanceAllowed(record)`
- `handleB1ConfidenceSelection(value)`

For supported B1 auto-graded records, clicking a confidence button now:

- updates the existing matching evidence record;
- disables confidence buttons during the transition;
- advances through the existing `proceed()` path;
- does not call `checkB1Answer()`, `appendB1EvidenceRecord()`, `recordB1Progress()`, or `b1UpdateDailyAfterAnswer()`.

The existing `Weiter` button remains available as the skip-confidence path, preserving `confidence:null`.

## 6. Supported Routes

Supported where the current route uses the B1 auto-graded `checkB1Answer(...)` flow and produces `result:"correct"` or `result:"wrong"`:

- Today's B1 Sprint
- B1 Diagnostic Sprint auto-graded items
- Connector / Grammar Sprint auto-graded items
- Redemittel auto-graded items
- Wortschatz auto-graded items

## 7. Excluded Routes, if any

Excluded from auto-advance:

- Production cards, because they are self-marked practice evidence only.
- Assisted / Teach me records, because "I knew it" style labels would be misleading after assisted practice.
- Old Case Trainer, because it does not use the B1 evidence/confidence flow.

Excluded records can still use the existing `Weiter` path.

## 8. Stored Confidence Values

Stored values remain unchanged:

- `sure`
- `unsure`
- `guessed`
- `null`

Dynamic labels were added without changing stored values:

- Correct: `I knew it`, `I was unsure`, `I guessed`
- Incorrect: `I thought I knew it`, `I was unsure`, `I guessed`
- Assisted/production/unknown: generic labels remain.
