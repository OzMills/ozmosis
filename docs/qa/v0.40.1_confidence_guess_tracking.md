## Confidence UI behaviour

After B1 feedback appears, Ozmosis now shows a compact optional confidence row with three secondary buttons:

- Sure
- Unsure
- Guessed

The row is optional. Continuing without selecting a value leaves `confidence` as `null`.

## Stored confidence values

Stored values are stable internal strings:

- `sure`
- `unsure`
- `guessed`
- `null` when no selection is made

Translated labels are not stored as values.

## Evidence update method used

`appendB1EvidenceRecord()` still creates the evidence record at answer/mark-practised time. The runtime stores the active evidence record id. `updateLatestB1EvidenceConfidence(value)` then finds that same record by id, current item id, and session id, and updates only its `confidence` field.

## Duplicate-prevention method

Confidence selection updates the existing evidence record. It does not call `appendB1EvidenceRecord()` and does not create a second evidence entry. Changing a confidence selection updates the same record.

## Auto-graded item confidence result

Runtime testing verified confidence updates on auto-graded B1 items for:

- correct answer + `sure`
- wrong answer + `unsure`
- additional answered item + `guessed`
- no selection leaves `confidence: null`

## Production-card confidence result

Production-card confidence capture is implemented on the existing mark-practised flow. After a production card is marked practised, the same confidence row appears and updates the practised evidence record without changing production-card scoring semantics.

## Export/import result

Evidence remains exported through the existing evidence payload. Exports with confidence values include those values because the evidence array is exported as data. Old exports without evidence/confidence remain accepted by the existing import path.

## Backward compatibility result

The confidence field was already part of the v0.40 evidence schema. v0.40.1 only changes some records from `confidence: null` to one of the stable confidence strings. Existing evidence records and old exports remain compatible.
