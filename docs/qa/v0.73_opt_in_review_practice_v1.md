## 4. Review Practice Scope

v0.73 adds a narrow opt-in Review Practice route startable from Dev Tools. It uses preview-ready existing B1 items only and does not add Home/Menu/Learning Map integration yet.

## 5. Selection Rules

Review Practice uses `buildB1ReviewCandidatePreview()` and selects up to 8 `preview_ready` candidates. It records no generated content and uses current content items only.

## 6. Empty State

If no preview-ready candidates exist, Review Practice shows:

`Not enough older practice yet. Do Today’s B1 Sprint first.`

No evidence is recorded by the empty state.

## 7. Evidence Recording

Review attempts record normal item evidence plus additive metadata:

- `reviewContext: "opt_in_review_v1"`
- `reviewCandidateReason`
- `reviewDelayBucket`
- `daysSinceLastAttempt` where safely known

No storage key changed and no migration was added.

## 8. Completion Copy

Completion copy says review checks older items again and does not prove mastery. It does not use durability or readiness labels.

## 9. Review Activation Result

Review practice is opt-in and narrow. No scheduler, recurring queue, due/overdue learner copy, Leitner activation, push/reminder, streak, mastery claim, B1-readiness claim, or durability state was added.

## 10. Scoring Impact

Scoring logic was unchanged. Review practice records normal item attempts through the existing answer flow.

## 11. localStorage Impact

Protected storage keys remain unchanged. Review context is additive metadata inside normal evidence records only.

## 12. Export/Import Impact

Export version is now `v0.73-opt-in-review-practice-v1`. Current imports accept additive review metadata and recent older imports remain compatible.

## 13. Content Bank Impact

No content-bank files were changed. Review Practice uses existing current B1 items only.

## 14. Route Smoke
