## 4. Queue Scaffold Implementation

Added read-time queue helpers that map routeable repair candidates to existing registry items, dedupe items, balance task depths, and expose queue summaries.

## 5. Queue Source Data

Queues use current evidence, v0.63 repair candidates, current item registry metadata, and existing practice items only.

## 6. Existing Item Selection

Item selection filters out production cards and selects only existing normal-eligible items whose metadata/text matches the candidate family.

## 7. Candidate-to-Queue Mapping

Routeable connector/word-order, repair, and case/article candidates can produce queue previews if enough matching existing items are available.

## 8. Fallback Handling

Non-routeable candidates and candidates without enough matching items return no queue and explain the reason.

## 9. Not Enough Matching Items Handling

The scaffold refuses to create a queue with fewer than four matching existing items.

## 10. Dev Tools Preview

Added a no-save Dev Tools repair queue preview with candidate selection, item IDs, and item-selection reasons.

## 11. Learning Map Impact
