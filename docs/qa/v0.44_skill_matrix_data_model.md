## 5. Skill Matrix Data Source

- evidence key: `ozmosis_b1_progress_evidence_v1`;
- Learning Map node taxonomy and matching helpers;
- B1 content registry / bank lookup;
- existing task-depth derivation;
- existing confidence values;
- existing metadata-provenance handling.

No new persistent progress model or localStorage key was added.

## 6. Matrix Shape

`b1SkillMatrixData()` returns:

- `schemaVersion`
- `generatedAt`
- `levelTrack`
- `taskDepths`
- `rows`
- `globalSummary`
- `limitations`

Each row contains:

- `nodeKey`
- `label`
- `cluster`
- `cells`
- `rowSummary`

Each cell contains:

- evidence/correct/incorrect/practised counts;
- production and diagnostic counts;
- confidence counts;
- metadata provenance;
- bank counts;
- attempt-context counts;
- conservative state;
- limitations.

Existing item task types are mapped conservatively into these cells. Diagnostic attempts keep their original task depth and are also counted by diagnostic context.

## 9. Cell State Rules

Allowed states only:

- `not_enough_evidence`
- `introduced`
- `emerging`
- `developing`

Rules are intentionally cautious:

- zero records: `not_enough_evidence`;
- one record: `introduced`;
- multiple records: `emerging`;
- three or more positive/practised records without errors or guessed/unsure evidence: `developing`.

No mastery, reliability, durability, transfer-ready, readiness, or pass/fail states are emitted.

## 10. Metadata Provenance

Cells track:

- `explicit`
- `derived`
- `unknown`

Derived metadata remains visible. The matrix does not pretend derived evidence is canonical explicit item metadata.

## 11. Confidence / Guess Handling

Cells count:

- `sure`
- `unsure`
- `guessed`
- `unset`

Diagnostic test evidence confirmed a selected `guessed` confidence value appeared in the relevant cell.

## 12. Diagnostic Evidence Handling

Diagnostic evidence contributes to the relevant skill/task cell but remains limited:

- `diagnosticEvidenceCount` counts unique diagnostic evidence records in the global summary.
- `diagnosticCellEvidenceCount` counts matrix-cell placements, which can be higher because one record may map to more than one row.
- Diagnostic cell limitations state that diagnostic evidence is a starting snapshot, not placement.

## 13. Production Evidence Handling

Production evidence remains conservative:

- counted as practised/production evidence;
- not counted as auto-graded correct or incorrect;
- marked with limitations:
  - Production is self-marked.
  - No automatic correctness evidence.
  - Treat as practice evidence only.
