# Ozmosis v0.85.3.8 Manual Phone Test Checklist

Patch: v0.85.3.8 - HUD, Keyboard, and Live Mobile Verification Gate

Use this checklist on a real phone after the local automated gate passes. This file is required because the Codex environment can emulate mobile and keyboard-like viewports, but cannot prove real browser chrome, touch ergonomics, or real soft-keyboard behaviour on a physical device.

## Device Setup

- Open the current GitHub Pages deployment or a local network-served copy on a phone.
- Test in portrait.
- If possible, test one iPhone Safari session and one Android Chrome session.
- Clear old local app state only if the test requires a fresh first-run path.

## Required Screens

- Home loads without horizontal scrolling.
- A normal choice practice item fits above the HUD.
- A wrong choice answer shows feedback, confidence buttons, and Continue without obstruction.
- A typed cloze item keeps the input and Prüfen reachable when the keyboard opens.
- A correction item keeps the textarea and Prüfen reachable when the keyboard opens.
- A Satzbau item keeps the typing surface and Prüfen reachable when the keyboard opens.
- B1 cases/articles feedback keeps the compact article grid visible and usable.
- Case Trainer feedback keeps the article table/grid readable and the next action reachable.
- Settings/Data exposes Export Save and Import Save.

## HUD and Keyboard Checks

- The bottom HUD never covers the active answer input.
- The bottom HUD never covers Prüfen.
- The bottom HUD never covers confidence buttons.
- The bottom HUD never covers Continue.
- Focusing a typed answer field does not trap the learner at the bottom of the page.
- Scrolling remains possible while the keyboard is open.

## German LTR Checks

- German prompts remain left-to-right.
- German answer inputs remain left-to-right.
- German cloze text remains left-to-right.
- German model/correction text remains left-to-right.
- German article-table labels remain readable.

## Pass / Fail Notes

- Pass only if all primary controls remain visible or reachable with a small scroll.
- Fail if the learner must guess that a hidden control exists.
- Fail if the HUD blocks the current task or next action.
- Fail if the app horizontally scrolls at body level.

Manual result: not run in Codex.
