## 4. Screenshot Issue Map

- Blocker: menu drawer scrollability, Settings reachability, and clipped Close control.
- High UX friction: false sequencing on Home and route hubs, inconsistent activity flow, production-card clutter, HUD/Weiter hierarchy, Case Trainer header/help mismatch.
- Clarity/copy: Diagnostic result repetition, Learning Map debug-like recommendation details, raw Skill overview copy, Options/Settings naming ambiguity.
- Accessibility/responsive: mobile Skill Matrix table readability, cloze sizing, toast layer placement, 44px touch targets, Arabic UI with German LTR content.
- Safe deferrals: full production-card UX redesign, v0.58 Skill Matrix logic QA, weakness repair, delayed review, and new route architecture.

## 5. Information Architecture Changes

- Home now groups actions as Recommended next, Check progress, Practice, Planned, Tools, Tester, and System.
- Large ordinal numbers were removed from Home route cards.
- Route card badges now describe purpose: `CHECK`, `EVIDENCE`, `PRACTICE`, `PLANNED`, and `TOOL`.

## 6. Home Navigation Results

- Diagnostic Sprint and Learning Map are grouped as progress-checking actions.
- Grammar, Wortschatz, and Redemittel are grouped as practice actions.
- Planned routes are visually secondary and shorter.
- Case Trainer is presented as a tool, not a numbered curriculum step.

## 7. Route Hub Results

- Grammar and Redemittel hubs no longer use ordinal numbering.
- Hub cards now show activity type and short descriptors such as Mixed practice, Topic drill, Repair, Contrast, and Self-marked.
- Existing route targets and Today’s B1 Sprint composition were preserved.

## 8. Menu Drawer Scroll / Close Results

- Drawer now has a fixed viewport shell and a single inner `.menuScroll` container.
- Settings is reachable through an explicit `Open Settings` shortcut and the full settings form stays collapsed by default as Quick settings.
- Close is now an icon-sized 48x44 control and was not clipped in Edge/CDP viewport validation.
- Escape closes the drawer.

## 9. Options / Settings Naming Results

- Home now labels the global settings entry as Settings.
- The drawer section is Settings, with Quick settings collapsed by default.
- Case Trainer setup is titled `Case Trainer Setup` with `Round options` for drill-specific controls.

## 10. Active Practice Flow Results

- Answer -> feedback -> confidence / Continue without confidence rhythm is preserved.
- Continue without confidence remains a null-confidence path.
- No new activity flow changed scoring, task composition, or evidence meaning.

## 11. Production Card Results

- Production cards now default to task prompt plus learner-controlled reveals.
- Useful phrases and Self-check are separate details controls.
- Example answer reveal labels the answer as one possible answer.
- `I practised this` still records self-marked production evidence only.
- `I can't do this now` skips the production card and records no production-practice evidence.

## 12. Diagnostic Flow Results

- Pre-start copy is shorter and explicitly says the sprint is not a score or exam.
- Result screen now uses snapshot summary, caution signals, needs-more-evidence, Open Learning Map, and Home.
- Diagnostic evidence remains snapshot/context evidence.

## 13. Learning Map Results

- Suggested Next Practice default copy is shorter.
- Raw rule/count/schema details were removed from the default learner-facing recommendation card.
- The reveal now uses learner-facing explanation such as rules-based suggestion, closest available route, and no delayed review evidence.
- v0.57 recommendation metadata remains available through debug output.

## 14. Mobile Skill Matrix Results

- Narrow screens now get a card/list Skill Matrix presentation.
- The wide matrix table remains available behind a `Matrix table` details control.
- Evidence calculation and conservative states were not changed.

## 15. Case Trainer Harmonisation Results

- Setup title clarifies Case Trainer-specific scope.
- Help actions are clearer: `Teach me` remains the assisted action, while the article table action is labelled `Show table` / `Article table`.
- Header/menu overlap was checked in route smoke.
- Case Trainer scoring, storage, Genitive options, and article table logic were preserved.

## 16. Cloze / Input Blank Results

- Typed cloze blanks now size closer to answer length with a smaller cap.
- Mobile CSS constrains inline cloze widths to avoid dominating the sentence.
- Choice gaps remain separate from typed-input styling.
- Answer checking was not changed.

## 17. Feedback / Confidence / Weiter Results

- Incorrect B1 feedback now says `Not quite` instead of `Wrong`.
- Correct feedback can show a concise micro-rule where metadata exists.
- Confidence buttons use shorter visible labels: Knew it, Unsure, Guessed.
- Weiter after feedback is now labelled `Continue without confidence` where it is the null-confidence path.

## 18. Toast / Exit Message Results

- Exit status copy was shortened.
- Toast/status message is positioned at the safe top layer, auto-dismisses faster, and does not intercept pointer events.

## 19. HUD / Footer Results

- HUD remains available in active practice.
- HUD is hidden on completed result states to avoid competing with result actions.
- Production and diagnostic result actions have bottom clearance and were checked for obstruction.

## 20. Arabic / LTR Results
