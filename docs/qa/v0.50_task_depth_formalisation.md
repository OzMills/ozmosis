## 6. Legacy Value Normalisation

Read-time alias mapping was added for known variant values, including:

- `connector_choice`, `phrase_choice`, `multiple_choice`, `choice` -> `recognition`
- `grammar_cloze`, `vocab_cloze`, `redemittel_cloze`, `phrase_cloze`, `typed_cloze` -> `cloze`
- `word_order_cloze`, `word_order`, `satzbau` -> `sentence_building`
- `error_repair`, `correction`, `korrektur` -> `repair`
- `production_card`, `self_check` -> `controlled_production`
- `delayed_review` -> `review`

Malformed or unknown values canonicalise to `unknown`.

Diagnostic context is used as `diagnostic` only when no more specific task depth is available from record or item metadata.
