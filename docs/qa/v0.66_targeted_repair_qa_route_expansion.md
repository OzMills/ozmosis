## 4. Targeted Repair QA

The v0.65 Edge/CDP gate passed after the patch. It covered no queue/no start, thin evidence, diagnostic-only evidence, self-marked production-only evidence, routeable queue start, targeted repair session flow, evidence recording, confidence update, continue-without-confidence, completion copy, export/import, route smoke, responsive smoke, and Arabic/LTR smoke.

## 5. Queue Quality Gate

Added `b1RepairQueueQualityGate(...)` so queues expose a high-quality gate result and reasons. Targeted repair remains available only when a candidate is routeable, has exact existing-route fit, has at least four selected existing items, and does not depend on unsafe support/confidence-only evidence.

## 6. Route Expansion Decisions

Routeability remains conservative. Word order, connector meaning/syntax, case/article, repair accuracy, and repeated capitalisation evidence can become routeable only when existing items match. Support/confidence remains context-only and does not create a targeted repair queue.

## 7. Candidate Families Audited

- Word order: allowed where existing Grammar repair/connector items match.
- Connector meaning/syntax: allowed where existing Connector Sprint items match.
- Case/article: allowed where existing case/article items match.
- Repair accuracy: allowed where existing repair items match.
- Support/confidence gap: not routeable; context only.
- Capitalisation/orthography: routeable only after repeated correct-with-note evidence and existing repair items.

## 8. Existing Item Matching
