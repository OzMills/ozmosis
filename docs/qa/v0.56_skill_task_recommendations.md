## 4. Current Recommendation Logic Before Patch

Before v0.56, Suggested Next Practice handled thin evidence, early weak signals, and under-tested task types, but it did not explicitly rank repair gaps, contrast gaps, connector word-order gaps, or support-level context before falling back to broad under-tested cells.

## 5. Skill-Task Recommendation Logic

Added conservative recommendation helpers for task-depth gaps. The primary recommendation can now detect:

- repair evidence gap after constrained recognition/cloze/sentence evidence;
- contrast evidence gap after cloze or sentence evidence;
- connector word-order gap when connector meaning/contrast evidence exists but sentence-building or repair evidence is thin;
- support-context gap when most evidence for a row is scaffolded or self-marked.

## 6. Skill Matrix Use

The logic reads existing Skill Matrix rows and cells. It does not create persistent aggregates and does not change the Skill Matrix data model.

## 7. Repair Evidence Use

Edge/CDP synthetic evidence validated a `wortschatz` cloze pattern that recommended `repair` only after enough evidence existed to leave the diagnostic baseline.

## 8. Contrast Evidence Use

Edge/CDP synthetic evidence validated a connector pattern with sentence-building and repair evidence but no contrast evidence. The recommendation became `task_depth_contrast_gap` with taskDepth `contrast`.

## 9. Support-Level Use

Support-level evidence is used only as context. Edge/CDP synthetic scaffolded connector records produced `support_context_gap` with cautious copy: support level is evidence context, not a score.

## 10. Production Evidence Limits

Production remains self-marked practice evidence only. Recommendation copy and limitations continue to avoid treating production as auto-graded correctness.

## 11. Diagnostic Evidence Limits

Thin evidence still recommends the Diagnostic Sprint as a starting snapshot. Diagnostic copy remains framed as a baseline, not a score or exam.

## 12. Learner-Facing Copy Audit
