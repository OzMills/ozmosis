## 4. UX Audit Method

Used Microsoft Edge headless through Chrome DevTools Protocol against a local static HTTP server. The harness captured console errors, runtime errors, DOM state, route smoke, layout dimensions, viewport overflow, menu behaviour, active-practice state, evidence behaviour, keyboard checks, Arabic/LTR checks, and export/import checks.

## 5. Screenshot Failure Mapping

- Header/status/menu overlap: fixed by hiding the debug stamp during active practice and tightening mobile header controls.
- Back/menu collision risk: fixed with a stable 44x44 mobile control lane and active-practice header padding.
- Home card/pill clipping: fixed with mobile two-column card layout and wrapping pills.
- Coming Soon clipping: fixed through the same route-card/pill constraints.
- Oversized menu/settings modal: reduced to route groups first, tools second, options below, with close control and safe scrolling.
- Active practice blank-space/HUD pressure: reduced by starting typed/long-answer practice content near the top on mobile and keeping HUD clearance.
- Confidence/Weiter competition: confidence remains primary; Weiter becomes `Skip confidence / Weiter` when confidence-as-next is available.
- Repair pseudo-diff: nonsense answers now use the whole-sentence fallback.
- Pre-answer `Correct:` support label: pre-answer support now rewrites that prefix to `Meaning:`.

## 6. Header / HUD Fixes

Added a v0.53.1 CSS shell pass for debug stamp containment, active-practice debug-stamp suppression, mobile header sizing, fixed exit-control sizing, and safe-area-aware menu bounds. HUD obstruction checks passed across the tested viewport matrix.

## 7. Home / Tool Hub Fixes

Home cards now constrain children with `min-width:0`, wrap status pills on small screens, and avoid body-level horizontal overflow. Required route-card labels, action pills, and Coming Soon pills were not clipped in Edge/CDP.

## 8. Menu / Navigation Fixes

The menu now has Practice, Tools, and Options sections, a close button, safe viewport bounds, scrollable overflow, and delegated handlers for Diagnostic Sprint, Learning Map, Wortschatz, and Tester Notes. Escape and Space-on-close both closed the menu in browser validation.

## 9. Active Practice Layout Fixes

Mobile typed cloze and long-answer practice now align from the top instead of consuming avoidable vertical whitespace. Check, feedback, confidence, Weiter, and HUD stayed reachable in the browser matrix.

## 10. Feedback / Repair UX Fixes

`b1RepairTokenDiff(...)` no longer emits precise token changes for very short or structurally unrelated answers. Nonsense repair answers now show corrected sentence, learner answer, and `Try rewriting the whole sentence.` Concise existing micro-rules remain available.

## 11. Safe-Area / Viewport / Scroll Fixes

The menu uses `100dvh` with safe-area insets and internal scrolling. Active-practice HUD checks reported no essential controls blocked by the fixed footer. No body-level horizontal overflow was detected in any tested viewport.

## 12. Typography / Density / Visual Hierarchy Fixes

Mobile Home route cards use tighter responsive type, smaller route-number pressure, wrapping pills, and constrained children. Active practice now suppresses the debug stamp so learner content and controls remain dominant.
