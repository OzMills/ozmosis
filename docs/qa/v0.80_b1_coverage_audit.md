## 4. Coverage Audit Method

Added `buildB1CoverageAudit()` as a read-time audit over the current B1 registry banks. It uses existing item metadata, derived metadata coverage, task depth, bank key, skill tags, grammar focus, contrast targets, and item surface text to classify item-count coverage by planned B1 cluster.

This audit does not store data, mutate content, change scoring, create routes, or generate learner progress claims.
