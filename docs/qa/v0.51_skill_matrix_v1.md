## 4. Browser Validation Method

Browser validation used Microsoft Edge headless through Chrome DevTools Protocol.

This was used because:

- the in-app Browser plugin still fails in this environment with `windows sandbox failed: spawn setup refresh`;
- bundled Playwright still cannot load because `playwright-core` is missing.

Edge/CDP loaded the app from `http://127.0.0.1:8793/index.html`, captured console/runtime errors, clicked real DOM controls, measured rendered layout dimensions, and ran the required responsive viewport matrix.
