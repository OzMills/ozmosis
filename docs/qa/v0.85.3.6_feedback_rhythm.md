## 5. Feedback Problems Before Patch

The post-answer state still behaved like stacked legacy feedback in places: repeated nested borders, star/status copy embedded inside feedback, dense explanation blocks, and confidence controls competing visually with old feedback cards.

## 6. Feedback Rhythm Contract

The target rhythm is:

1. compact result state;
2. corrected answer/sentence;
3. one concise micro-rule or contrast note;
4. optional compact support block such as the article grid;
5. full post-answer result/star area;
6. confidence or continue controls.

## 7. Implementation Changes

- Added `feedbackRhythmBlock` CSS for post-answer surfaces.
- Added `b1PostAnswerResultAreaHtml(...)` for the full post-answer star/result area.
- Updated B1 feedback rendering to use the feedback rhythm class and place star/result output in the dedicated post-answer area.
- Updated Case Trainer feedback cards to use compact result, answer, and rule hierarchy.
- Updated production skipped/practised feedback to use the same rhythm without changing production evidence semantics.
- Added `scripts/ozmosis-feedback-rhythm-check.cjs`.
