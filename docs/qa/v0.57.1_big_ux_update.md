## 4. Full UX Inventory

Audited Home, menu drawer, active practice shell, choice items, typed cloze, word-order cloze, repair, contrast, production cards, assisted state, diagnostic state, Grammar, Wortschatz, Redemittel, Diagnostic Sprint, Learning Map, Skill Matrix / Task-depth matrix, Options, Case Trainer, Dev Tools, Known Bugs / Tester Notes, export/import UI, route transitions, feedback, confidence-as-next, and mobile/desktop responsive states.

Issue map:

- Critical blocker: none found after the starting v0.57 gate.
- High UX friction: menu exposed too much Options content by default; feedback had decorative star noise; route titles and route lists were oversized on small screens; cloze blanks looked less intentional than the surrounding sentence.
- Visual polish: spacing, borders, card rhythm, Home recommendation layout, lower Home sections, secondary route hierarchy, and technical tools needed stronger hierarchy.
- Accessibility: focus style and menu focus return needed consolidation; drawer close target needed to remain compact but 44x44+.
- Learner-cognition risk: support labels and production scaffolds needed clearer names so English support and self-marked practice did not read as grading.
- Safe deferral: deeper Skill Matrix QA, production-card redesign, weakness repair, delayed review, error-pattern detection, and any scheduler work remain deferred.
