## 5. Issue Map

- Critical blocker: none found in v0.75 gate.
- High UX friction: Home had too many equal-weight learner and QA surfaces.
- Visual hierarchy: Advanced/QA and Settings were too visible in the learner default path.
- Access hierarchy: Menu needed Continue/Practice/Progress/Settings grouping.
- Evidence overexposure: Learning Map needed a stronger summary-first lead area.
- Learner-cognition risk: review and evidence surfaces needed more distance from debug cockpit language.
- Accessibility/responsive: v0.75 passed overflow checks, but desktop and short-height layouts needed more intentional use of space.
- Safe deferral: content metadata repair, learner-readable export, durability QA, review stabilisation, and B1 coverage audit were left for later stages.

## 6. Home Redesign

Home now leads with “What should I do now?”, a single dominant recommended action, and a “Why this appears” disclosure. Today’s B1 Sprint is a clear secondary action. Advanced / QA is collapsed by default.

## 7. Menu Redesign

Menu is grouped into Continue, Practice, Progress, Settings, and Advanced / QA. It includes Home, Today’s B1 Sprint, Recommended next, practice routes, Learning Map, Diagnostic Sprint, Settings, Tester Notes, and Dev Tools.

## 8. Settings Redesign

Settings keeps global support language and practice/data controls out of Case Trainer. Desktop layout now separates language from settings controls.

## 9. Learning Map Redesign

Learning Map now uses a summary-first lead grid before drill-down evidence details. The Skill Matrix remains collapsed inside Evidence details.

## 10. Review Practice UX

Review Practice remains optional, secondary, and actionable-only. Copy stays framed as practising older items again, not mastery or durability.

## 11. Active Practice / Feedback UX

Practice shell semantics were unchanged. CSS refinements keep German prompts visually central and preserve answer -> feedback -> confidence/continue rhythm.

## 12. Production Card UX

Production remains self-marked only. Existing reveals and skip/practised actions were preserved and screenshot-tested.

## 13. Case Trainer Harmonisation

Case Trainer remains accessible from Practice. Global language remains in Settings, not Case Trainer. Setup, active, and feedback states were screenshot-tested.

## 14. Desktop / Tablet / Short-Height Layout

Home, Learning Map, and Settings now use wider desktop layouts. Short-height laptop active practice was captured and smoke-tested.

## 15. Visual System Consolidation

The pass reduces default border intensity, collapses lower-priority QA areas, softens inactive panels, and keeps cyan for primary/interactive focus.
