## 4. v0.85.3.6a Baseline Used

The accepted v0.85.3.6a feedback-rhythm repair gate was used as the baseline. The patch preserved the shared feedback rhythm, post-answer result section, confidence row, and article-grid integration from that baseline.

## 5. Correction Surface Problems Before Patch

Full-sentence correction/edit-text surfaces used the shared single-line answer input. That made longer repair answers harder to edit and did not visually distinguish full-sentence correction from short cloze answers.

## 6. Correction Input / Textarea Decision

Implemented a correction-only textarea for full-sentence correction, edit-text repair, and transformation surfaces. The textarea is not used for cloze, choice, production, or Case Trainer surfaces.

## 10. Satzbau Surface Problems Before Patch

Word-order/Satzbau items were visually treated like generic typed cloze items. Existing word chunks were not separated strongly enough from the answer field.

## 11. Satzbau Chunk/Input Design

Added a visual-only `satzbau` surface for `word_order_cloze` items. Existing `learnerCue` chunks render as compact neon chips, and the same inline typed-cloze answer path remains in use.
