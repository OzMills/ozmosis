## 9. Review Tests Workflow

Review Tests were added to Dev Tools only.

The workflow starts active, renderer-compatible, review-flagged imported rows, then preserves the normal task flow before asking:

`Did the test need editing?`

Buttons:

- `No`
- `Yes, add to edit list`

The Review Edit List:

- stores under `ozmosis_b1_review_edit_queue_v1`;
- dedupes by `sourceRowAuditKey`;
- has popup, copy, close, and clear controls;
- exports and imports additively.

Copy format:

`categoryId<TAB>taskType<TAB>sourceRowAuditKey<TAB>itemId<TAB>issueCodes<TAB>humanReviewReason`
