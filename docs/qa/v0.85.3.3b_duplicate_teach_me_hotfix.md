## 4. Duplicate Teach Me Bug Evidence

Manual screenshot review identified duplicate B1 cloze Teach Me controls. Source inspection confirmed both controls were rendered: `#hintBtn` from `renderB1DisplayHintButton()` and `#noArticleBtn.teachBtn` from the older inline-cloze action path.

## 5. Root Cause

`renderB1Question()` configured `#noArticleBtn` as `Teach me` for inline cloze, then `renderB1DisplayHintButton()` also exposed `#hintBtn` as `Teach me` when the display model had a revealable hint.

## 6. Implementation Change

Added `b1CurrentDisplayHintIsRevealable()` and changed `updateB1TypedClozeActionState()` so the older `#noArticleBtn.teachBtn` is hidden/disabled whenever the new display-model reveal hint button is available.

## 7. Surviving Teach Me Control

The surviving control is the newer smaller secondary `#hintBtn` `Teach me` reveal button.

## 8. Suppressed Duplicate Control

The suppressed duplicate is the older B1 inline-cloze `#noArticleBtn.teachBtn` action when a revealable display hint is available.
