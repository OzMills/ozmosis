## 4. v0.85.3.6 Issues Found

- Nested feedback mini-card styling remained visible in proof screenshots.
- The post-answer result/star area still looked like a compact pill.
- The cloze fail proof showed `B1-Niveau` but displayed a stale `wenn/als` contrast note.
- The contact sheet showed labels/empty boxes rather than loaded thumbnails.
- Responsive results recorded `confidenceVisible:false` while the QA report claimed confidence was reachable.

## 5. Nested Feedback Repair

Feedback-rhythm CSS now overrides older compact feedback rules with a higher-specificity selector. Micro-rules, choice feedback, transformation feedback, and correction patterns no longer render as separate bordered mini-cards inside the feedback block.

## 6. Post-Answer Result/Star Repair

The post-answer result area now has a visible `Result` heading, stronger section padding, a left accent, and larger section styling. It remains absent before answering.

## 7. Cloze Feedback Mismatch Root Cause

The mismatch was not in the content item. The staged item had the correct prompt, answer, and micro-rule. The root cause was contrast detection using raw submitted answer text; the QA wrong answer `falsch` contains `als`, which triggered the `wenn/als` contrast group.

## 8. Cloze Feedback Mismatch Fix

Raw submitted answer text was removed from contrast-group detection. The cloze fail proof now shows the `B1-Niveau` rule and rejects stale `wenn/als` feedback in the repair harness.

## 9. Contact Sheet Repair

The repair harness waits for all contact-sheet images to load before capture, verifies all `comparison.html` image references exist, checks loaded image dimensions, and checks the contact-sheet PNG size. The new contact sheet contains real screenshots.

## 10. Confidence Visibility Check Repair

Responsive checks now stage and answer a B1 item before measuring confidence controls. The result JSON records `confidenceReachableAfterB1Answer:true` for all checked viewports.

## 11. Choice Feedback Results
