## 4. Home / Landing Page

Home now has a session-only first-use tester card when no B1 evidence is present. The Home hero uses the existing rules-based recommendation helper and opens only existing routes through `openB1RecommendationRoute()`. Today’s B1 Sprint composition and connector exclusion policy were not changed.

## 5. First-Use / Tester Guidance

Added a compact “New to this test build?” card with `Start diagnostic` and `Skip for now`. Dismissal is session-only; no new localStorage key was added.

## 6. Known Bugs / Tester Notes

Added a Tester Notes / Known Bugs modal with known limitations and reporting prompts. It includes `Copy tester report`, `Copy debug snapshot`, and `Close`.

## 7. Tester Report

Added a safe tester-report copy helper. The report includes app version, route, mode, current item ID when available, timestamp, viewport, user agent, storage key existence/count summary, compact recommendation summary, and layout warnings.

Excluded: full localStorage, full evidence history, private typed answers, full progress export, and full answer/model dumps.

## 8. Active Practice Layout

The existing v0.45 top-left exit control and diagnostic pre-start flow were preserved. No new active-practice explanations were added.

## 9. Feedback Layout

No broad renderer rewrite was made. Existing concise feedback cards remain in place.

## 10. Sprint Complete Screen

B1 completion now uses “Sprint complete”, “Correct this time”, “Progress saved locally. This is evidence, not mastery.” and “Incorrect this time” copy instead of making the percent accuracy the main heading.

## 11. Learning Map Density

Learning Map ordering was adjusted to put Current Focus before Suggested Next Practice and to rename the main list to “Skill overview”. Technical evidence details remain behind disclosures.

## 12. Production Cards

Production cards keep Show model and Mark practised. A visible note says: “Self-marked practice. Ozmosis does not auto-grade this.”

## 13. Dev Tools

Dev Tools now includes `Copy tester report` and `Tester Notes / Known Bugs` beside the existing debug snapshot and Skill Matrix snapshot tools. Dev item preview remains labelled no-save.

## 14. Microcopy Audit

Visible copy was tightened in the Home hero, first-use guidance, sprint-complete screen, Learning Map ordering, and production-card note. No mastery, durability, B1-ready, review-due, or auto-grading claims were added.

## 15. Visual System Alignment

The patch keeps the dark neon console aesthetic and existing card/chip patterns. It does not add unsupported mockup concepts such as percentages, ranks, due review, repair queues, or mastery labels.

## 16. LocalStorage Impact
