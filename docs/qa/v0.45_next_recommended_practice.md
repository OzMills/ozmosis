## 7. Recommendation Object Shape

`b1NextRecommendedPractice()` returns:

- `schemaVersion`
- `generatedAt`
- `levelTrack`
- `primary`
- `alternatives`
- `inactiveRules`
- `globalLimitations`

The primary recommendation includes id, title, route key/label, node key, task depth, priority rule, confidence, evidence basis, why lines, limitations, and an existing-route action.

## 8. Rule Priority Implementation

- Overdue review: inactive. Reason: no delayed review system is active yet.
- Weak skill / early weak signal: active when incorrect, unsure, or guessed evidence creates a cautious weak signal.
- Under-tested task type: active when a Skill Matrix row has evidence but a preferred task-depth cell is thin.
- Recent misconception pattern: inactive. Reason: robust repeated error-pattern recommendation is not active yet.
- Current focus continuation: fallback for empty/thin evidence or no safer rule.
