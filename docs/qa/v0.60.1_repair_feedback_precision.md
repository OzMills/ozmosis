## 4. Current Repair Feedback Before Patch

Repair feedback showed corrected sentence, submitted answer, broad rule/contrast detail, and fallback copy together by default. It could explain the original target rule even when the learner had already fixed that target and only left a capitalisation issue.

## 5. Correct-with-Note Implementation

Added repair-only comparison helpers. For repair answers that match after safe German case-folding and are not capitalisation-target tasks, the attempt is scored as correct with additive metadata:

- `correctWithNote: true`
- `orthographyNote: true`
- `orthographyType`

No storage key, confidence value, support-level value, or task-depth value was changed.

## 6. Capitalisation Handling

Capitalisation-only repair differences now produce concise notes for:

- `sentence_initial_capitalisation`
- `noun_capitalisation`
- `mixed_capitalisation`

Capitalisation-target repair tasks remain strict when metadata identifies capitalisation as the target.

## 7. Exact Diff Handling

Repair feedback now puts the smallest useful correction first. A one-token article repair such as `der -> die` is shown directly. Large answer differences fall back to: `Several changes needed. Compare with the corrected sentence.`

## 8. Explain Reveal Handling

Longer corrected sentence, submitted answer, rule, target-rule, contrast, and accepted-with-note details are moved behind an `Explain` disclosure for repair feedback.

## 9. Translation Label Handling

English support text is sanitized at render time so learner-facing support starting with `Correct:` is shown as `Meaning:`. Content bank source strings were not edited.

## 10. Scoring Impact

Only repair answers that satisfy the target answer except for safe capitalisation-only differences are upgraded to correct-with-note. This is the explicit narrow scoring exception allowed for v0.60.1.

## 11. Evidence Impact

Correct-with-note records one normal auto-graded repair evidence record with additive orthography metadata. Confidence updates the same evidence record and does not create a duplicate.

## 21. Known Risks

- Correct-with-note relies on exact case-fold equality, so it intentionally does not correct spelling, punctuation beyond existing normalization, or word-order issues.
