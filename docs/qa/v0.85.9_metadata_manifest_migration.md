## 4. Manifest Schema Decision

The manifest file is `content/b1-metadata-manifest.js`.

The manifest global is `window.OZMOSIS_B1_METADATA_MANIFEST_V1`.

The manifest is loaded with a normal non-module script tag. It does not use fetch, dynamic import, or a build step.

The manifest contains metadata-only entries. Forbidden learner-facing fields such as prompts, answers, accepted answers, choices, feedback, explanations, and translations are not present in manifest entries.
