## 4. Completion Gate Findings

v0.69.1 was close but not clean enough to advance. The completion gate found first-paint exposure risk, static language-selector ownership still tied to Case Trainer markup, first-run language labels that did not exactly match the intended learner-facing labels, generated browser-profile artefacts, and missing v0.69.2 canonical documentation.

## 5. True Boot / First Paint

Added a small boot shell and `body.booting` state so learner routes, overlays, status UI, and Case Trainer setup cannot flash before app routing and first-run language setup complete. The boot state is removed after `init()` and first-run language-panel handling.

## 6. Static Language Ownership

The visible support-language selector is now statically owned by Settings through `#settingsLanguageHost`. Runtime movement from Case Trainer into Settings was removed. The old Case Trainer language-panel block remains as hidden inert legacy markup because deleting the mojibake-adjacent block was riskier than preserving a hidden block; browser QA verifies `#startScreen > .languagePanel` is absent and visible language ownership is Settings.

## 7. First-Run Labels

First-run language options now render as:

- `English`
- `Türkçe`
- `العربية`
- `中文`
- `Українська`

The harness verified the exact labels and Arabic first-run selection without reversing German learning content.
