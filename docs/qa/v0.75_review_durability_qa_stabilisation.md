## 4. Stabilisation Scope

v0.75 stabilises the v0.70-v0.74 review/durability foundation. It does not add a scheduler, Leitner queue, due/overdue learner state, durability state, mastery claim, B2 content, scoring change, storage migration, or content-bank edit.

## 5. Review Readiness Audit

Review readiness remains QA-only in Dev Tools/debug/tester output. It reports coverage and blockers without activating learner-facing durability states.

## 6. Review Eligibility Audit

Eligibility remains internal/read-time/no-save. It excludes diagnostic-only, self-marked production-only, missing/unmapped, missing timestamp, too-recent, and unsafe task records.

## 7. Review Candidate Preview Audit

Candidate preview remains no-save and Dev Tools-readable. v0.74 learner integration uses it only when preview-ready candidates exist.

## 8. Opt-in Review Practice Audit

Review Practice remains opt-in, existing-item-only, and limited to preview-ready candidates. Empty states remain honest and record no evidence.

## 9. Evidence Duplication Audit

Review answers record one normal evidence item. Confidence updates the existing evidence item once and does not duplicate the attempt.

## 10. Claim Audit

Learner-facing review copy avoids due/overdue, weak, slipping, mastered, durable, reliable, B1-ready, and readiness claims. Review is framed as optional older-item checking.

## 11. Home / Menu / Learning Map Audit

Home, Menu, and Learning Map show Review Practice only when older auto-graded candidates are available. No broken empty review card is shown to new users.

## 12. Dev Tools / Tester Notes Audit

Tester Notes now explicitly says Review Practice is optional and appears only when older auto-graded items are available. Dev Tools review copy distinguishes internal eligibility/preview from learner-facing actionable review.

## 13. Export/Import Audit
