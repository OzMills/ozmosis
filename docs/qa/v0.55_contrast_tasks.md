## 4. Current Contrast Handling Before Patch

The app already had task-depth categories, connector items, word-order cloze items, repair items, and Skill Matrix contrast columns, but contrast feedback was mostly implicit through item copy or micro-rules. Existing evidence did not expose contrast group context in debug/tester paths.

## 5. Contrast Task / Metadata Implementation

Added conservative contrast helpers in `index.html`: `b1ContrastGroup(...)`, `b1ContrastTargets(...)`, `b1ContrastFeedback(...)`, and `renderB1ContrastNote(...)`. New evidence can now carry additive `contrastGroup` and `contrastTargets` fields where the current item metadata or prompt text supports a safe inference. No scoring logic uses these fields.

## 6. Dative vs Accusative Handling

The helper recognises case contrast when existing item text or metadata indicates dative/accusative opposition. No new case content was added.

## 7. Location vs Movement Handling

The helper recognises location/movement contrast where current item text or metadata supports it and uses concise copy: location with a two-way preposition points to dative; movement/direction points to accusative. No new location/movement bank was added.

## 8. V2 vs Verb-Final Handling

Word-order contrast feedback was added for connector items and cloze/repair items where current metadata indicates subordinate-clause or main-clause connector behaviour. Edge/CDP validated a word-order cloze item with a contrast note.

## 9. weil / denn / deshalb Handling

The helper can distinguish `weil`, `denn`, and `deshalb` contrast groups and provides concise subordinate-clause versus main-clause consequence feedback when those connectors appear in the item or learner answer.

## 10. obwohl / trotzdem Handling

The helper handles the high-yield `obwohl` / `trotzdem` contrast. Edge/CDP validated a connector choice item where an incorrect known contrast answer produced a useful contrast note.

## 11. damit / um ... zu Handling

The helper recognises `damit` / `um ... zu` contrasts and frames them as subject-sensitive purpose clauses versus same-subject infinitive construction where current item text supports it.

## 12. wenn / als Handling

The helper recognises `wenn` / `als` contrast and limits feedback to repeated/conditional time versus one-time past event. No B2-only explanation was added.

## 13. bevor / nachdem Handling

The helper recognises `bevor` / `nachdem` and keeps the contrast to before/after sequencing. No new content was added.

## 14. Support-Level Interaction
