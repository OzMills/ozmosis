## 4. Eligibility Scope

v0.71 defines conservative internal review eligibility rules only. It does not create a learner-facing review route, review queue, scheduler, due/overdue copy, durability labels, mastery claims, or B1-readiness claims.

## 5. Eligibility Implementation

Added `buildB1ReviewEligibility(records, contentIndex)` with:

- current content item mapping
- timestamp validation
- auto-graded evidence checks
- diagnostic-only exclusion
- self-marked production-only exclusion
- same-session exclusion
- unsupported production-card task exclusion
- QA-only interval buckets

## 6. Eligibility Rules

An item group is eligible only when:

- `itemId` exists
- the item maps to current B1 content
- timestamp is parseable
- the original parseable attempt is auto-graded
- the latest auto-graded attempt is at least 1 day old
- the evidence is not diagnostic-only
- the evidence is not self-marked production-only
- the item is not an unsupported production card

## 7. Exclusion Handling

Exclusion counters include:

- `missing_item_id`
- `missing_item`
- `missing_timestamp`
- `diagnostic_only`
- `self_marked_only`
- `no_auto_graded_evidence`
- `original_not_auto_graded`
- `too_recent`
- `ambiguous_repeated_attempts`
- `unsupported_task_type`
