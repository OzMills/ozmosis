## 4. Durability / Review Gate Scope

v0.70 is a design gate only. It adds internal QA visibility for whether future review/durability work has enough evidence foundations. It does not add a learner-facing review system.

## 5. Readiness Snapshot Implementation

Added `buildB1DurabilityReadinessSnapshot(records)`, a no-save helper that summarises:

- total evidence records
- timestamp coverage
- itemId coverage and current-content mapping
- repeated item attempts
- possible delayed attempt pairs
- task-depth spread
- auto-graded, self-marked production, diagnostic, and legacy/other evidence counts
- confidence coverage
- support-level coverage
- blockers before active review

## 6. Dev Tools Exposure

Added a Dev Tools-only `Review readiness snapshot` section. It shows the same QA limits clearly:

- no review schedule is active
- no learner-facing durability states are active
- no mastery or B1-readiness claim is made
- no progress or evidence is saved by opening the snapshot

## 7. Debug / Tester Report Impact

The readiness snapshot is included in:

- `buildDebugSnapshot()`
- `testerReportSummary()`
- `window.ozmosisB1Debug().durabilityReadiness`

The tester/debug surfaces expose counts and blockers, not learner answer text.
