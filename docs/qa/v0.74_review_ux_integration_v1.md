## 4. Review UX Scope

v0.74 exposes the existing opt-in Review Practice route in learner-facing navigation only when `buildB1ReviewCandidatePreview()` reports preview-ready older auto-graded candidates.

## 5. Home Integration

Home now shows a compact Review Practice section only when actionable. Empty/no-candidate Home states do not show a broken review card.

## 6. Menu Integration

The menu includes a Review practice button under Practice only when actionable. It starts the existing opt-in review practice route.

## 7. Learning Map Integration

Learning Map shows a cautious Review Practice panel only when actionable. The copy says review is extra practice for older items and not a mastery or durability claim.

## 8. Empty State Handling

When no review candidates are available, the v0.73 honest empty state remains active: `Not enough older practice yet. Do Today's B1 Sprint first.`

## 9. Copy / Claim Audit
