## 4. Existing Export Flow

The existing JSON export/import flow remains in place and unchanged as the data backup/import format.

## 5. Learner-Readable Export Implementation

Added an optional Markdown learning summary with copy and download controls under Settings/Data. It includes app version, export time, current focus, recent practice, skill overview, task-depth evidence, review practice status, production limitation, what the summary does not prove, and a safe tutor note.

## 6. Privacy / Typed Answer Handling

The report is derived from summaries and does not include raw typed answers, raw localStorage keys, raw evidence payloads, or session logs.

## 7. Learner-Facing Claim Audit

The report states: "This is a learning summary, not an exam result." It avoids broad completion percentages and unsupported mastery/readiness claims.

## 8. Progress State Labels

Skill overview uses the existing safe progress labels only: Not tested, Not enough evidence, Introduced, Emerging, and Developing.

## 9. Review Practice Summary

The report describes Review practice as optional older auto-graded item checking when available. It does not describe a scheduler, due state, score, or proof of long-term recall.

## 10. Production Limitation Copy

The report states that production cards are self-marked practice only and that Ozmosis does not grade open writing or speaking as correct.
