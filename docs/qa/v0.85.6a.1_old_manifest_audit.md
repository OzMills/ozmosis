## Findings

- The old manifest overused `Core Safe unchanged` because it did not have the replacement-source layer.
- The corrected model separates imported-source rows from legacy/seed rows instead of treating every unmatched row as a deletion-style exception.
- Duplicate lineage is now labelled as resolved, same-decision, conflicting, or unresolved rather than one broad conflict flag.
- Production/self-marked rows are separated from normal auto-graded practice buckets.
