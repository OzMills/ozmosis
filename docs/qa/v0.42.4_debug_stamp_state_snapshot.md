## 4. Debug Stamp

The app now shows a small fixed debug stamp in the top-right corner.

Fields displayed:

- app version;
- current route/mode;
- current round position where available;
- active item ID where available;
- viewport size.

Example from local smoke:

```txt
v0.42.4 | b1_diagnostic | 1/18 | b1_vocab_unterlagen_004 | 1280x720
```

The stamp is pointer-events-none, LTR, compact, and did not create horizontal overflow in the tested viewport. It does not show learner answers, selected choice text, prompts, model answers, localStorage, or evidence history.

Tested routes with stamp updates:

- Home;
- Today's B1 Sprint;
- B1 Diagnostic Sprint;
- Connector Sprint;
- Redemittel;
- Wortschatz;
- Case Trainer.

## 5. Debug Snapshot Export

Dev Tools now includes `Copy debug snapshot`.

Clipboard behavior:

- Clipboard copy succeeded in the in-app browser after permission was available.
- Clipboard fallback was also observed: when clipboard access was blocked, a selectable textarea appeared with the snapshot JSON.

Included fields:

- app name/version/export version;
- timestamp;
- route/mode/active round type;
- viewport, device pixel ratio, scroll position;
- document language/direction;
- safe active element metadata;
- round index/total/queue state;
- current item ID, bank, task type, task depth, CEFR, grammar focus, and skill tags where available;
- feedback/confidence row state;
- storage key names/existence/counts;
- evidence count and latest evidence summary;
- registry and content bank counts;
- compact Learning Map scaffold summary;
- layout bounds and warning flags.

Deliberately excluded:

- full localStorage dump;
- full evidence history;
- full progress export;
- learner typed answer;
- selected answer text;
- all model answers/content banks;
- analytics/tracking identifiers.

## 6. Layout Warning Detection

Implemented warning fields:

- `footerOverlapPossible`;
- `activeElementNearViewportBottom`;
- `horizontalOverflowDetected`;
- `bodyScrollLocked`;
- `mainScrollLocked`;
- `unknownActiveItem`;
- `missingEvidenceKey`;
- `missingProgressKey`.

Limitations:

- These are lightweight diagnostic flags, not a full visual layout engine.
- Footer overlap checks only compare current active-element and HUD/footer bounds.
