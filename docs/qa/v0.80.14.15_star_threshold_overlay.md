## Star Threshold Overlay Behaviour

The overlay uses threshold coverage:

- 1-star layer width = percentage of targets with star level at least 1;
- 2-star layer width = percentage of targets with star level at least 2;
- 3-star layer width = percentage of targets with star level at least 3;
- 4-star layer width = percentage of targets with star level at least 4;
- 5-star layer width = percentage of targets with star level at least 5.

The renderer draws the 1-star layer first and the 5-star layer last, so higher-star layers sit above lower-star layers.

## Progress Model Risk Check

The existing category calculations already used threshold counts:

- `category.starCounts[level]` increments when `target.starLevel >= level`;
- `percentAt1Star` through `percentAt5Star` are calculated from those threshold counts.

The patch did not change star earning or scoring. It changed rendering only.
