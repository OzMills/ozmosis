## Source Inspection Result

- B1-02 through B1-11 include imported planning-style metadata that sometimes describes slash alternatives, style/register repair targets, or English support text.
- The beta-blocking issue was renderer contract alignment, not a need to broadly rewrite content banks.
- The patch therefore normalises task presentation at render time while preserving content IDs, answers, and statuses.

## Task Contract Repairs

- `Kontrast` slash alternatives now generate choice buttons.
- Selected valid/style/register repairs now generate bounded choice buttons.
- Ordinary repair prompts now use a German instruction plus the broken German sentence.
- `Luecke` keeps one inline typed blank.
- `Satzbau` remains typed sentence-building.
- `Produktion` remains self-marked only.

## Practice UX Repairs

- Cloze blanks use a compact standard width.
- Long answer and feedback text wraps safely.
- Touch controls have visible active/press feedback.
- The HUD progress strip is thicker.
- In very short landscape B1 practice states, the fixed HUD is hidden to avoid covering primary controls.

## Support Visibility Result

- Repair tasks hide pre-answer support where source support would reveal the answer.
- Choice tasks with visible source support defer that support until after answer.
- German learning content remains LTR.

## Production Semantics Result

- Production cards still use existing self-marked controls.
- `I can't do this now` skips without evidence.
- `I practised this` records self-marked production evidence with `answerMode:"mark_practised"`.
- No production correctness is inferred.

## Review Practice Result
