## Root Cause Summary

- Choice buttons selected an answer but still required `Prüfen`, creating an unnecessary two-step interaction for pure button-choice tasks.
- B1 continuation still offered skip-confidence copy after normal answers.
- Inline cloze Teach Me and Prüfen were visible together, competing for attention.
- B1 practice screens had accumulated scroll and max-height rules that could trap Edge/Chromium wheel scrolling.
- Prompt scale, prompt-to-choice spacing, input outlines, and progress visibility were still too heavy for beta testing.

## UX Changes Implemented

- Choice-button B1 tasks submit immediately on click/tap through `checkB1Answer`.
- Typed cloze, repair text, Satzbau, and Case Trainer text input still use explicit `Prüfen`.
- Confidence buttons are ordered `I GUESSED`, `I WAS UNSURE`, `I KNEW IT`.
- Auto-graded and assisted B1 submissions block continuation until confidence is selected.
- Confidence writes to the current evidence record and does not create a duplicate record.
- Inline cloze action state now shows `Teach me` before input and switches to `Prüfen` after typing.
- Teach Me copy now reads `Practice answer — This will reappear at the end of the session for recall.`
- B1 scroll rules now prefer document scrolling, with HUD clearance retained.
- Prompt size, choice spacing, cloze punctuation, input outline weight, button tapdown feedback, and HUD progress thickness were tightened.
