## 4. Current Pattern/Error Visibility Before Patch

v0.61 showed cautious possible-pattern cards but did not yet group repeated signals into learner-friendly error-type categories.

## 5. Error-Type Summary Implementation

Added derived `b1ErrorTypeSummaries(...)` helpers, learner copy, existing-route hints, Learning Map rendering, and debug snapshot output. Summaries are computed from current evidence and v0.61 QA-hardened pattern signals.

## 6. Supported Error Types

- Word order
- Connector choice
- Case/article choice
- Repair accuracy
- Support gap
- Confidence gap
- Capitalisation
- Production evidence limited

## 7. Deferred Error Types

Detailed subtypes such as specific connector pairs, gender-vs-case separation, and targeted repair-queue categories are deferred to later design work.

## 8. Threshold Handling

No evidence and one wrong answer produce no error-type summary. Capitalisation summaries require repeated correct-with-note records.

## 9. Correct-with-Note Integration

Repeated correct-with-note orthography evidence can produce a `Capitalisation` summary. A single minor note does not create a strong learner-facing summary.

## 10. Learning Map Impact

Learning Map now includes a compact `Recent error types` section when summaries exist. Details remain behind `Explain`.

## 11. Recommendation Impact

Suggested Next Practice remains conservative and unchanged except for sharing the same evidence layer. Error-type summaries do not replace or overrule recommendations.

## 12. Skill Matrix Impact

Skill Matrix evidence logic is unchanged. The v0.62 gate reused matrix regression fixtures and no-overflow checks.

## 13. Dev Tools / Tester Report Impact
