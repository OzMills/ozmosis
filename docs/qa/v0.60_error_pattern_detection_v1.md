## 4. Current Evidence Pattern Capability Before Patch

Before v0.60, Ozmosis exposed evidence, confidence, support, task-depth, matrix QA, recommendation QA, and debug summaries, but it did not compute repeated error-pattern signals.

## 5. Error Pattern Detection Implementation

Added derived/read-time helpers around `b1ErrorPatternSignals(...)`, learner copy, debug summary, and a modest Learning Map Possible patterns section. No pattern data is stored.

## 6. Pattern Families Supported

Supported: connector meaning/syntax, word order after connectors, case/article metadata, repair task depth, support/confidence context.

## 7. Pattern Families Deferred

Deferred: delayed-review patterns, production correctness, broad vocabulary semantic diagnosis, targeted repair queues, generated content, and weakness repair sessions.

## 8. Thresholds / Insufficient Evidence Handling

Learner-facing pattern signals require at least three relevant attempts and at least two matching error/context signals, except support/confidence context which requires at least four relevant attempts and repeated support/low-confidence context. One wrong answer and two thin attempts do not produce learner-facing pattern signals.

## 9. Connector Pattern Handling

Connector patterns are split between word-order after connectors and connector meaning/syntax evidence where task-depth and metadata support that distinction.

## 10. Word Order Pattern Handling

Word-order signals use connector/word-order metadata, sentence-building task depth, word-order cloze, or repair context. Copy says "Possible pattern" and "not a diagnosis."

## 11. Case / Article Pattern Handling

Case/article signals require repeated evidence with cases/articles metadata. Recommended route is the existing Case Trainer.

## 12. Repair Pattern Handling

Repair signals require repeated repair-context evidence. Recommended route uses existing Grammar.

## 13. Support / Confidence Pattern Handling

Support/confidence context detects repeated scaffolded or low-confidence context without changing scoring. It is framed as context for a small next practice step, not a score.

## 14. Production Evidence Limits

Self-marked production alone does not produce correctness or error-pattern signals. Production remains practice evidence only.

## 15. Learning Map Impact

Learning Map can show a small Possible patterns section only when signals exist. No-signal states omit the section.

## 16. Recommendation Impact

Suggested Next Practice remains conservative and unchanged as the primary recommendation engine. Pattern route buttons open existing routes only.

## 17. Debug / Tester Report Impact

`debugErrorPatternSummary()` and `window.ozmosisB1Debug().errorPatternSummary` expose signal metadata without dumping typed learner answers.

## 18. Scoring Impact
