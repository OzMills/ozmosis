## 7. Implementation Summary

The B1 choice renderer now normalises current string-choice schemas and future object-choice schemas, shuffles choices at fresh item render time, and stores the displayed order on the active item as `_choiceRenderState`.

The selected answer is tracked by displayed choice id and text. Correctness is resolved from explicit `isCorrect`, stable choice ids where available, or canonical answer text. It no longer depends on displayed A/B/C position.

The same active item keeps the same displayed order through answer submission, feedback, confidence selection, and active-item debug inspection. Fresh item renders may shuffle differently.

Malformed duplicate correct-answer text is flagged as ambiguous in debug metadata and is not marked correct from text alone.

## 21. Known Risks

- Current route starts are intentionally random, so a route may contain choice items in the queue even when the first item is cloze or repair.
