## 4. v0.85.3.4 Contract Usage

Used `docs/OZMOSIS_SHARED_PRACTICE_FRAME_CONTRACT_v0.85.3.4.md` as the implementation boundary. The patch implements only the convergence layer for shared frame metadata and article-grid adapter forms. It does not start the feedback rhythm pass.

## 5. Current Convergence Implementation

Added a shared practice-frame metadata layer and declared article-grid adapter around the existing Case Trainer table data. B1 and Case Trainer typed-answer states now expose common frame metadata without merging their scoring/evidence systems.

## 6. Shared Frame Metadata

Active practice states now expose additive DOM metadata:

- `data-practice-frame`
- `data-answer-surface`
- `data-route-source`
- `data-launch-source`
- `data-feedback-surface`
- `data-article-grid-mode`

These attributes support QA and future convergence work. They do not affect learner scoring or evidence.

## 7. Article Grid Adapter

Added `renderArticleGridAdapter(...)` and small normalisation helpers around existing DER/EIN/KEIN article-table data. The adapter supports:

- full grid;
- compact highlighted grid;
- optional reveal grid.

It does not change article values or Case Trainer answer checking.

## 8. Full Grid Result

Case Trainer full article-grid support remains available. The convergence gate captured `case-trainer-full-grid-reveal.png`.

## 9. Compact Grid Result

Wrong article/case feedback can render a compact highlighted grid. The convergence gate captured:

- `b1-cases-articles-repair-wrong-with-compact-grid.png`
- `article-grid-compact-feedback.png`
- `case-trainer-wrong-answer-grid.png`

## 10. Optional Reveal Result

Case Trainer `Show table` / hint support now renders through the adapter as optional reveal mode. The convergence gate captured `article-grid-optional-reveal.png`.

## 11. B1 Cases / Articles Repair Result

B1 cases/articles repair feedback can show compact article-grid support only when metadata explicitly identifies article family, case, and gender/number. The grid is not shown before answer. It is not shown for correct B1 answers in this patch.

Metadata-gap fallback: if the item is a pronoun case, broad family contrast, or lacks explicit article family/case/gender metadata, no B1 article grid is rendered. This avoids guessing.

## 12. Same Typed-Answer Frame Result

B1 typed repair and Case Trainer typed article/cloze answers still use their existing render/check functions, but both now expose shared frame metadata and route/source slots. This is convergence, not a full renderer rewrite.
