# Ozmosis v0.50 Browser Gate - Edge/CDP Clarification

## Purpose

This note records the browser-validation path that opened the gate for v0.51 work.

## Starting Version

The repository-root app verified as:

- `OZMOSIS_APP_VERSION = "v0.50"`
- `OZMOSIS_EXPORT_VERSION = "v0.50-task-depth-formalisation"`

## Blocked Browser Paths

The in-app Browser plugin path remained blocked by the local runtime failure:

```txt
windows sandbox failed: spawn setup refresh
```

The bundled Playwright fallback remained unavailable because the bundled `playwright` package could not load `playwright-core`.

No in-app Browser plugin pass or Playwright pass is claimed for this gate.

## Accepted Browser Path

Microsoft Edge headless via Chrome DevTools Protocol successfully loaded the repo-root app from a local static server.

The validation used:

- local static server at `http://127.0.0.1`;
- installed Microsoft Edge headless;
- Chrome DevTools Protocol page/runtime/log events;
- captured console errors;
- captured runtime exceptions;
- real DOM state and DOM clicks;
- rendered layout measurements.

## Result

Edge/CDP loaded v0.50 successfully with:

- console errors: `0`;
- runtime errors: `0`;
- task-depth schema: `v1`;
- Skill Matrix rows: `8`;
- Learning Map nodes: `8`.

The v0.51 implementation was allowed to proceed only because Edge/CDP provided working browser validation in this environment.
