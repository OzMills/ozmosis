# Ozmosis v0.80.14.11

## Source-Preserving Import Wiring and Runtime QA Pass

Ozmosis v0.80.14.11 is a narrow correction pass after v0.80.14.10. It verifies source preservation and fixes runtime/import wiring problems without rewriting source content or creating a parallel task set.

The patch preserves the reconciled source package and source CSV hashes. It keeps excluded, human-review, generated-bank, and preview-only rows available for Dev Tools Review Tests and QA, while preventing them from leaking into normal learner routes, Today’s B1 Sprint, Review Practice, B1 Path progress, learner-facing recommendations, or normal scoring.

## What Changed

- Added source-preservation before/after manifests for read-only source packages and CSV files.
- Added a v0.80.14.11 static gate that checks source hashes, runtime syntax, protected storage keys, route eligibility, mojibake, field mapping, completed-item filtering, repair feedback rendering, and required report generation.
- Added a v0.80.14.11 Edge/CDP browser smoke that loads the static app locally, checks normal route samples, Review Tests, Review Edit List, Learning Map, export/import UI visibility, responsive Home states, and Arabic/LTR behaviour.
- Repaired runtime encoding corruption in `index.html`, including German umlauts, `ß`, UI symbols, language labels, and affected button text.
- Hardened normal learner-route selection so completed/max-star items are excluded from ordinary practice selection.
- Kept normal imported learner practice limited to route-ready `PRACTICE_FAMILIES` and `CONTRAST_SETS` rows.
- Preserved raw/generic bank-generated rows, human-review rows, and CAT18 preview rows for Dev Tools and QA-only workflows.
- Added safe empty-state handling when a route has no unfinished practice items.
- Added repair feedback guards so renderer output does not show self-comparisons such as `die Krankenkasse -> die Krankenkasse`.
- Preserved Home grouped route collections: Learn, Review, Progress, Production, Tools, and Settings.
