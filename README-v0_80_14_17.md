## Patch Summary

v0.80.14.17 is a narrow visual/progress-card consistency patch.

It:

- applies the requested five-colour star palette to compact star indicators and visible star detail rows;
- reduces the mobile mini star-percentage indicators;
- aligns mini indicators with a deterministic compact grid;
- keeps the Star Threshold Overlay threshold-coverage calculation unchanged;
- makes Learning Map B1 Path collection cards use the same compact card structure as the landing-page B1 Practice cards.

## Preserved Behaviour

- German-learning content unchanged.
- Task answers unchanged.
- Scoring semantics unchanged.
- Star-earning semantics unchanged.
- Star Threshold Overlay calculation unchanged.
- localStorage key names unchanged.
- Export Save / Import Save workflow preserved.
- No backend, framework, build step, package manager, dependency, account, analytics, API call, runtime AI, or runtime German generation added.

## Run Locally

Ozmosis is a static browser app. For local testing, run:

```bash
python -m http.server
```

Then open the local address shown by Python, usually `http://localhost:8000/`.
