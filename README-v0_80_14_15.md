# Ozmosis v0.80.14.15

## Star Palette / Star Threshold Overlay

Ozmosis v0.80.14.15 is a narrow UI/progress-visualisation patch after v0.80.14.14.

It updates the five-star palette and corrects B1 Path/Home progress bars to use a Star Threshold Overlay model. The progress bars now show coverage for targets that have reached at least each star threshold, rather than implying additive segments.

## What Changed

- Updated the five-star palette:
  - 1 star: Bronze `#b87333`
  - 2 stars: Silver `#b8c4d6`
  - 3 stars: Gold `#f2c94c`
  - 4 stars: Sky Blue `#38bdf8`
  - 5 stars: Electric Cyan `#67e8f9`
- Added a central star palette map in `index.html`.
- Added `buildStarThresholdOverlayData(...)` for display-only threshold overlay data.
- Re-rendered B1 Path and Home path progress bars as overlaid threshold layers.
- Updated star glyph classes so star levels map to Bronze, Silver, Gold, Sky Blue, and Electric Cyan.
- Updated the compact B1 Path legend to include palette labels.

## Preserved

- Scoring semantics.
