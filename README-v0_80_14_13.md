# Ozmosis v0.80.14.13

## Landing Page Visual Reference Alignment

Ozmosis v0.80.14.13 is a narrow visual alignment patch after v0.80.14.12. It rebuilds the Home landing page to follow the supplied mobile reference while keeping the app static, dependency-free, and route-compatible.

The landing page now uses a centred dark neon shell with the reference order:

- Ozmosis title and menu control.
- Recommended Task.
- First visit mini-test prompt.
- B1 Practice path cards.
- Practice Modes.
- Case Trainer.
- Progress.
- Writing / Speaking.
- Settings and Advanced / QA.

## What Changed

- Reworked the Home markup into reference-matched sections with live buttons and existing routes.
- Added a final Home CSS override that forces the reference single-column shell order across mobile, tablet, and desktop widths.
- Added B1.1, B1.2, and All Practice path cards to the landing page with stacked star/progress visibility.
- Kept the supplied reference SVG/PNG as QA/design references only; the runtime UI remains real HTML, CSS, and JavaScript.
- Removed Home-only extra explanatory panels that were not in the supplied UI.
- Hid the legacy Review practice Home block from the landing page while preserving the underlying review route/tooling elsewhere.
- Matched the Recommended Task card text and route action so it opens the current B1.1 path route.
- Added v0.80.14.13 static and browser QA harnesses.
- Saved required responsive screenshots under `docs/qa/screenshots/v0.80.14.13/`.

## Preserved

- Main deployed file: `index.html`.
- Static browser app architecture.
- No backend, framework, build step, package manager, dependencies, accounts, analytics, external API calls, runtime AI, runtime German generation, or runtime morphology.
- Protected storage key names:
  - `ozmosis_b1_sprint_progress_v1`
  - `ozmosis_b1_progress_evidence_v1`
- Export/import compatibility, including v0.80.14.12-style imports.
- Source CSV/source ZIP immutability.
- Content bank files.
- Scoring, correctness, production self-marking, Today’s B1 Sprint composition, Review Tests, Review Edit List, Dev Tools, Settings, Learning Map, and Case Trainer.
- German learning labels/content remain LTR under Arabic support language.
