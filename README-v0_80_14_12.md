# Ozmosis v0.80.14.12

## Verification / Learner-Facing Artefact Hotfix

Ozmosis v0.80.14.12 is a narrow pre-v0.81 safety hotfix after v0.80.14.11. It makes the current package safer as the baseline for the next feature pass by fixing learner-facing source artefact leakage in routing/rendering only.

This patch does not edit source CSVs or source ZIPs. It does not generate replacement German tasks, create a parallel task set, add v0.81 Cases and Articles work, activate CAT18/B2, add Satzi, add Genitive expansion, add runtime AI, add a backend, add a framework, or add dependencies.

## What Changed

- Added a v0.80.14.12 static validation gate for learner-facing source/generated artefact leakage.
- Added a v0.80.14.12 Edge/CDP browser smoke covering deterministic source-artefact rows, seeded completed/max-star filtering, Review Tests, Review Edit List, production cards, export/import, responsive screenshots, and Arabic/German LTR behaviour.
- Added portable source-preservation manifest path normalisation while keeping strict file existence, size, and hash checks.
- Hardened normal learner route filtering for source-shaped prompt and choice artefacts.
- Normalised learner-facing multiple-choice display to suppress visible `A`/`B`/`C` source labels while preserving stable choice IDs, values, and shuffling.
- Structured production prompt metadata at render time into compact learner-facing sections: `Situation`, `Useful phrases`, `Self-check`, and `Show example answer`.
- Added safe empty-state copy to B1 module route starters when completed/max-star filtering leaves no unfinished items.

## Runtime Route Safety

Normal imported learner practice remains limited to route-ready `PRACTICE_FAMILIES` and `CONTRAST_SETS` rows.

Excluded from normal learner routes:

- human-review rows
- review-flagged rows
- generic generated bank rows
- CAT18/B2 preview rows
- source-shaped prompt artefacts such as `Beste Bitte um Lösung:`
- unsafe bare answer-letter choices
- production rows whose structured prompt labels cannot be safely rendered
- completed/max-star items in ordinary star-rated practice contexts

Excluded rows remain preserved for Dev Tools Review Tests, source/debug views, Review Edit List workflows, and export/import metadata.
