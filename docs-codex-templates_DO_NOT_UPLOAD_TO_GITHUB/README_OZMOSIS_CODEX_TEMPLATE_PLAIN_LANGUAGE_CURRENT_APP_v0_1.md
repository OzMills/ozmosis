# Ozmosis

Ozmosis is a browser-based German learning app for practical B1-level practice. It helps learners practise grammar, sentence structure, connectors, cases, vocabulary, and short written production through focused exercises, retries, and progress tracking.

## What Ozmosis is for

Ozmosis is designed to help German learners move from recognising grammar patterns to actively producing them.

It focuses on:

- practising realistic A2/B1/B1 German sentence patterns
- building confidence through short, focused practice sessions
- helping learners notice recurring weak spots
- encouraging retries instead of one-off right/wrong answers
- tracking learning evidence rather than only awarding points

## Who it is for

Ozmosis is for German learners working around the A2 to B1 level, especially learners who need repeated practice with:

- cases
- word order
- connectors
- adjective endings
- sentence repair
- cloze exercises
- short written production

It is especially useful for learners who understand some German grammar in theory but need more practice using it quickly, accurately, and independently.

## How to use the app

A typical practice session works like this:

1. Open Ozmosis in the browser.
2. Choose a practice mode, module, or sprint.
3. Read the prompt carefully.
4. Type, select, repair, or build the answer depending on the task type.
5. Submit the answer.
6. Check the feedback.
7. Retry mistakes where the app asks you to practise again.
8. Use hints, translations, or model answers where available.
9. Review progress through the learning map, results screen, or skill progress tools.

Ozmosis is designed for short, repeated sessions rather than long study marathons.

### Practice sprints

Short practice sessions help learners focus on a manageable number of questions at a time.

### B1 module structure

The app organises practice around B1 learning areas and practical German skills.

### Grammar and case practice

Ozmosis includes exercises for German cases, articles, sentence roles, and related grammar patterns.

### Connector practice

Connector exercises help learners practise words such as weil, denn, obwohl, trotzdem, wenn, als, bevor, nachdem, während, and similar B1 structures.

### Cloze typing

Cloze tasks ask learners to type missing words or phrases into a sentence.

### Sentence repair

Sentence repair tasks ask learners to correct or rebuild German sentences.

### Production cards

Some tasks ask learners to produce their own German. These are not always automatically checked, so the learner may compare their answer with guidance or a model answer.

### Confidence tracking

Some practice flows ask learners how confident they were, helping separate lucky guesses from secure knowledge.

### Retry flow

Mistakes can return for another attempt, so learners get practice with the exact areas they struggled with.

### Learning map and skill progress

Progress views help learners see which areas have been introduced, practised, or strengthened.

## How progress works

Ozmosis tracks progress through learning evidence, not just one-off correct answers.

This means:

- automatically checked tasks can show whether an answer was correct
- self-marked production tasks can still count as useful practice evidence
- repeated successful attempts matter more than a single lucky answer
- confidence may be tracked separately from correctness
- weaker areas can return for more practice
- progress is stored locally in the browser if local storage is enabled

The goal is not just to finish exercises. The goal is to build reliable German production.
