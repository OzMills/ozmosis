# Ozmosis v0.80.14.10

## Learner Route Filtering and Landing Hub Cleanup

Ozmosis v0.80.14.10 narrows normal learner routes after the v0.80.14.9 full B1 v0_2 import and cleans up the landing page into grouped route collections.

This patch does not delete imported source material. It filters route eligibility so non-final, human-review, preview, and generic bank-generated rows stay available for QA/debug workflows without appearing in normal learner practice, Today’s B1 Sprint, Review Practice, B1 Path stars/progress, learner-facing recommendations, or normal scoring.

## What Changed

- Added shared learner-route eligibility helpers for normal practice, Today’s B1 Sprint, Review Practice, B1 Path/star progress, learner-facing summaries, and evidence/progress records.
- Normal imported learner practice is temporarily limited to:
  - `PRACTICE_FAMILIES`
  - `CONTRAST_SETS`
- Excluded generic imported bank-generated rows from normal learner routes:
  - `WORTSCHATZ_BANK`
  - `COLLOCATION_BANK`
  - `REDEMITTEL_BANK`
- Excluded human-review and `move_to_human_review` rows from normal learner routes and normal progress.
- Preserved excluded rows for Dev Tools Review Tests, source/debug summaries, the Review Edit List workflow, and export/import metadata.
- Added route eligibility metadata to new evidence records, including normal/review/path/star/dev-review eligibility fields.
- Filtered learner-facing Learning Map, Skill Matrix, B1 Path, recommendations, progress summaries, repair candidates, diagnostics, and error-pattern summaries to use learner-eligible progress records.
- Corrected six source-ledger-backed choice rows in place so visible choices use the app-ready source row mapping rather than letter-only fallback choices.
- Reorganised Home into grouped route collections:
  - Learn
  - Review
  - Progress
  - Production
  - Tools
  - Settings
- Moved developer/QA access under the low-priority Settings group with the label `Developer / QA`.
- Kept the B1 Progress preview compact on Home and moved full progress detail to Learning Map.
- Reworded Home and Learning Map copy away from developer/evidence jargon where it was learner-facing.
