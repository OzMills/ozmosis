# Ozmosis Changelog v0.80.14.14

## v0.80.14.14 - Progress Summary Cache / Interaction Latency Hotfix

### Added

- Added additive B1 progress summary cache under `ozmosis_b1_progress_summary_v1`.
- Added summary rebuild from existing raw B1 evidence.
- Added incremental progress-summary updates when a learner completes a task.
- Added a static in-memory B1 content index for route, item, task type, review group, and practice-unit lookup.
- Added dev-only timing checks for key Home, route, summary, review, export, import, and task-completion paths.
- Added local validation at `_development-files/v0801414_progress_summary_cache_gate.cjs`.
- Added QA documentation at `docs/qa/v0.80.14.14_progress_summary_cache_latency_hotfix.md`.

### Changed

- Home and B1 progress surfaces now read compact summary/path data instead of repeatedly building the full Learning Map, Skill Matrix, evidence summary, and recommendation data on every Home render.
- Normal daily route filtering now uses the static content index and compact path progress where safe.
- Review practice preview work is deferred until after Home renders or until the review surface is opened.
- Incremental evidence writes now update the affected practice unit immediately and defer the heavier aggregate refresh out of the immediate answer-submit path.
- Export now includes the progress summary as an additive field when available.
- Import now clears/rebuilds the derived summary from raw evidence, including older exports that do not contain the summary key.
- Dev Tools/debug output now exposes summary key, validity, fingerprint, and recent timing information.

### Preserved

- Static single-file app architecture.
- No backend/framework/build step/package manager/dependencies.
- Existing German learning content and content bank files.
- Source CSV/source ZIP immutability.
- Protected localStorage key names.
- Existing raw evidence history.
- Export/import compatibility.
- Existing B1 scoring/correctness semantics.
- Production self-marking.
- `I can't do this now` production skip path recording no production evidence.
- Dev Tools and Review Edit List availability.
- Settings, Learning Map, Case Trainer, and existing routes.
- Today's B1 Sprint composition and B1-only active learner scope.
- German LTR handling inside Arabic support-language contexts.

### Not changed

- No v0.81 Cases and Articles work.
- No Satzi.
- No new German content.
- No source CSV or source ZIP edits.
- No backend/framework/dependencies.
- No runtime AI.
- No runtime German morphology.
- No mastery, fluency, exam-readiness, or certification claims.

### Known limitations

- The progress summary is a derived cache; raw evidence remains the rebuild source.
- If content routing metadata changes substantially, the summary may rebuild once after update/import.
- The deferred aggregate refresh still scans compact path targets, but it no longer blocks the immediate evidence-write path in normal browser timing.
- Full browser smoke was not completed in this pass because the in-app browser path was previously blocked by `CreateProcessAsUserW failed: 5`.
- Full Leitner scheduling remains deferred.
