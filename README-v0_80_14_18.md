## Patch Summary

v0.80.14.18 is a narrow bugfix after the compact star-card work in v0.80.14.17.

It:

- removes the visible numeric level prefix from compact mini star indicators;
- keeps star-level information in accessible labels;
- uses a filled `★` for the large aggregate star percentage;
- makes the large percentage mean secured star points out of all possible star points;
- keeps mini star percentages as threshold coverage;
- keeps the Star Threshold Overlay bar calculation unchanged;
- keeps Learning Map B1 Path cards vertical while using the same compact layout as the landing B1 Practice cards;
- fixes the Home Settings action so it opens Settings as its own screen;
- keeps Export Save and Import Save reachable in Settings / Data.

## Preserved Behaviour

- German-learning content unchanged.
- Task answers unchanged.
- Scoring semantics unchanged.
- Star-earning semantics unchanged.
- Star Threshold Overlay calculation unchanged.
- localStorage key names unchanged.
- Export Save / Import Save workflow preserved.
- No backend, framework, build step, package manager, dependency, account, analytics, API call, runtime AI, or runtime German generation added.

## Run Locally

Ozmosis is a static browser app. For local testing, run:

```bash
python -m http.server
```

Then open the local address shown by Python, usually `http://localhost:8000/`.
